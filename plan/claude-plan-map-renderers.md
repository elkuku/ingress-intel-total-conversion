Implementation Plan: Common Map Renderer Interface                                                                                                                                                                                         
                                                                                                                                                                                                                                            
 Goal                                                                                                                                                                                                                                       
                                                                                                                                                                                                                                            
 Create an abstraction layer allowing IITC-CE to switch between Leaflet and Mapbox GL JS renderers while maintaining full plugin compatibility.                                                                                             
                                                                                                                                                                                                                                            
 ---                                                                                                                                                                                                                                        
 Architecture: Facade Pattern with Adapters                                                                                                                                                                                                 
                                                                                                                                                                                                                                            
 IITC.map (Facade)                                                                                                                                                                                                                          
     │                                                                                                                                                                                                                                      
     ├── IMapRenderer interface                                                                                                                                                                                                             
     │       ├── LeafletAdapter (wraps L.map)                                                                                                                                                                                               
     │       └── MapboxAdapter (wraps mapboxgl.Map)                                                                                                                                                                                         
     │                                                                                                                                                                                                                                      
     ├── ILayerFactory interface                                                                                                                                                                                                            
     │       ├── LeafletLayerFactory                                                                                                                                                                                                        
     │       └── MapboxLayerFactory                                                                                                                                                                                                         
     │                                                                                                                                                                                                                                      
     └── Compatibility Shim (proxies window.map)                                                                                                                                                                                            
                                                                                                                                                                                                                                            
 Why this approach:                                                                                                                                                                                                                         
 - Backward compatibility: window.map API preserved for plugins                                                                                                                                                                             
 - Gradual migration: Plugins work without modification                                                                                                                                                                                     
 - Extensibility: New renderers can be added
